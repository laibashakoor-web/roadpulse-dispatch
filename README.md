## Getting Started

First, run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the result.

## Contact and Registration Emails

Both the Contact form and Driver Registration form submit to `POST /api/submit-form` and are sent directly to your email using SMTP (Nodemailer).

1. Copy `.env.example` to `.env.local`.
2. Set `SMTP_USER` to your full Gmail address.
3. Set `SMTP_PASS` to your Gmail App Password (not your normal Gmail password).
4. Keep `MAIL_TO=laibash3225@gmail.com` (or your preferred inbox).
5. Restart the dev server after editing environment variables.

You can start editing the page by modifying `app/page.tsx`. The page auto-updates as you edit the file.
